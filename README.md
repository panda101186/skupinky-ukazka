# Skupinky plavání – ukázka

Klikací ukázka aplikace Centra péče o matku a dítě (Písek) na sestavování skupin dětského plavání.
Slouží k připomínkování rozhraní. Jména dětí a rodičů, telefony a data narození jsou smyšlená;
nic se neukládá, po obnovení stránky se ukázka vrátí do výchozího stavu.

Připomínky: tlačítko **✎ Připomínka** vpravo nahoře.
